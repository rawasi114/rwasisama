# rawasi_integration — التكامل (التصنيع الداخلي)

موديول الجسر بين المقاولات والورشة. يعتمد على `rawasi_construction` و `rawasi_workshop`
معاً، ويحقّق **السيناريو الذهبي**: تصنيع بنود جداول الكميات داخلياً في الورشة بدل
الشراء الخارجي (وفر متوقع ٢٠–٣٠٪).

## لماذا موديول جسر مستقل؟
حتى لا يعتمد المقاولات على الورشة أو العكس (اقتران غير مرغوب). الجسر يجمعهما،
وهو النمط المعماري الصحيح في Odoo لربط تطبيقين مستقلين.

## التدفق (end-to-end)

```
بند BoQ (procurement_type = in_house_workshop)
   ↓ طلب مواد مقاولات → اعتماد المشرف → اعتماد الميزانية
   ↓ زر «تصنيع داخلي بالورشة»
rawasi.internal.workshop.order (تكلفة + هامش 0%/5%)
   ↓ «إنشاء أمر بيع داخلي» (الشريك الداخلي)
sale.order (is_internal_workshop=True)
   ↓ تأكيد الحسابات
rawasi.workshop.mo (is_internal=True → تتجاوز بوابات الدفع 50%/100%)
   ↓ تصنيع → اكتمال
نقل تلقائي لمخزن المشروع + قفل طلب المقاولات (issued)
   ↓
يستهلكه المهندس في DSR كأنه استلم المواد عادةً
```

## المكوّنات
- `rawasi.internal.workshop.order` — الموديل الرابط (الحالة، التكلفة، الهامش، السعر).
- توسعة `rawasi.material.request` — زر `action_internal_workshop_quote`.
- توسعة `sale.order` — علم `is_internal_workshop` + إنشاء MO داخلي عند التأكيد.
- توسعة `rawasi.workshop.mo` — ربط + تسليم تلقائي للمشروع عند `action_done`.
- `rawasi.dashboard.unified` — لوحة المالك الموحدة (مقاولات + ورشة + تصنيع داخلي).
- شريك داخلي «رواسي سما — مشاريع المقاولات» (يُنشأ مرة واحدة).

## التحليل المزدوج
المنتج المصنوع داخلياً تظهر تكلفته في خطتين تحليليتين منفصلتين: «مشاريع المقاولات»
(على المشروع) و«أقسام الورشة» (على القسم) — لقياس ربحية حقيقية على الجانبين.
