# كراسة الشروط والمواصفات — مركز صحي المداين بحائل

أُعيدت صياغة العرض الفني لمشروع **«إنشاء وتجهيز وتأثيث مركز صحي المداين بمدينة حائل»** على هيئة
**نموذج كراسة الشروط والمواصفات (إنشاء مباني)** المعتمد من وزارة المالية، وذلك ليتوافق بنفس
الاحترافية والعمق والتسلسل والترتيب مع كراسة الدفاع الجوي المرجعية
(*إنشاء وتجهيز وتأثيث ورشة صيانة للموقع 103 بحفر الباطن*).

## الملفات
| الملف | الوصف |
|------|-------|
| `كراسة_الشروط_والمواصفات_مركز_صحي_المداين_حائل.docx` | المستند النهائي القابل للتعديل (Word / عربي RTL) |
| `كراسة_الشروط_والمواصفات_مركز_صحي_المداين_حائل.pdf`  | نسخة PDF جاهزة للعرض والطباعة |
| `build_madain_booklet.py` | المصدر النصّي المُولِّد للمستند (لتعديل المحتوى وإعادة التوليد) |

## الهيكل (مطابق للكراسة المرجعية)
1. القسم الأول: مقدمة (البنود 1–9)
2. القسم الثاني: الأحكام العامة (10–26)
3. القسم الثالث: إعداد العروض (27–44)
4. القسم الرابع: تقديم العروض (45–49)
5. القسم الخامس: تقييم العروض (50–55)
6. القسم السادس: متطلبات التعاقد (56–63)
7. القسم السابع: نطاق العمل المفصل (64–67) — *مطوّع بالكامل لمركز صحي*
8. القسم الثامن: المواصفات (68–73)
9. القسم التاسع: متطلبات المحتوى المحلي (74)
10. القسم العاشر: الشروط الخاصة
11. القسم الحادي عشر: الملحقات

## الحقول المطلوب تعبئتها قبل الاعتماد (بين أقواس `[   ]`)
- اسم الجهة الحكومية المالكة وإسم الإدارة.
- رقم الكراسة وتاريخ الإصدار وتاريخ الطرح، وجدول مواعيد المنافسة.
- بيانات ممثل الجهة (الاسم/الوظيفة/الهاتف/الفاكس/البريد) ومكان التسليم.
- المساحة الإجمالية التقريبية للمركز الصحي.
- الكميات والأسعار والفئات في جدول الكميات (القسم السابع) من واقع المخطّطات.

## ملاحظات
- مدة تنفيذ المشروع: **18 شهراً** (مثبّتة في القسمين السابع والعاشر).
- البنود القانونية/الإجرائية (1–63) صيغت وفق نظام المنافسات والمشتريات الحكومية ولائحته التنفيذية.
- جدول الكميات وجداول العمالة والمواد المُدرجة **استرشادية** لتوحيد الهيكل، وتُعتمد القيم الفعلية من المخطّطات وجداول الكميات المرجعية.
