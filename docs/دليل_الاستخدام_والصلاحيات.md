## أولاً: الأدوار الوظيفية (الصلاحيات)

النظام فيه **٧ أدوار** + **مدير النظام (Admin)**. كل مستخدم يُعطى دوراً واحداً من
حقل **«الدور الوظيفي»** في بطاقة المستخدم.

| الدور | ماذا يستطيع |
|---|---|
| **مهندس الموقع** | إنشاء وتعديل: طلبات المواد، التقارير اليومية، عدم المطابقة، طلبات المعلومات، المستندات، اعتماد المواد، سندات الاستلام، أنشطة WBS. قراءة: المنافسات والبنود والميزانية والمستخلصات. |
| **مهندس التخطيط** | إدارة: المنافسات، جدول الكميات، الاستيراد، التسعير، التكاليف غير المباشرة، WBS، طلبات المواد. قراءة: المشتريات والعقود وذاكرة الأسعار. |
| **مدير المكتب الفني** | صلاحيات واسعة (إنشاء/تعديل) على أغلب الأقسام: المنافسات، البنود، الإعدادات، WBS، المشتريات، المستندات والجودة، العقود والمستخلصات والضمانات. |
| **مدير المشاريع** | كصلاحيات المكتب الفني + **اعتماد تجاوز الميزانية** في طلبات المواد. |
| **المحاسب** | إدارة: المستخلصات والضمانات البنكية. قراءة: المنافسات والميزانية والمشتريات والمستندات. |
| **الاستشاري الخارجي** | قراءة عامة + **مراجعة والرد** على: اعتماد المواد، عدم المطابقة، طلبات المعلومات (دون إنشاء أو حذف). |
| **المدير العام** | يرث **كل** الأدوار السابقة (صلاحية شاملة على المحتوى). |
| **مدير النظام (Admin)** | الوحيد الذي يستطيع **الحذف / الإلغاء / الإرجاع لمسودة** في كامل النظام. |

> **قاعدة الحوكمة المهمة:** أي سجل يُسجَّل في النظام **لا يُلغى ولا يُعاد لمسودة ولا
> يُحذف** إلا بواسطة مدير النظام (Admin). هذا متعمّد للحفاظ على سلامة السجل المؤسسي.

### كيفية منح الدور لمستخدم (للمدير العام / مدير النظام)
1. الإعدادات ← **المستخدمون والشركات ← المستخدمون**.
2. افتح المستخدم ← تبويب الصلاحيات.
3. حدّد **«الدور الوظيفي»** (مهندس موقع / تخطيط / مكتب فني / مدير مشاريع / محاسب /
   استشاري خارجي / مدير عام) ← احفظ.

## ثانياً: خطوات العمل (Workflows)

### ١) من المنافسة إلى المشروع
1. **المنافسات ← جديد**: أدخل اسم المنافسة والجهة والموعد.
2. **استيراد جدول الكميات**: زر «استيراد جدول الكميات» ← ارفع ملف Excel.
   - لو الملف **مُسعّر** (فيه عمود سعر/إجمالي) تُرفع الأسعار تلقائياً.
3. **بدء التسعير** ← أدخل/اضبط الأسعار (أو «تطبيق الهامش الافتراضي»).
   - استخدم زر **💡 اقتراحات الأسعار** أو **✨ تطبيق أفضل سعر** للاستفادة من ذاكرة الأسعار.
4. راجع الإجماليات (تكلفة/سعر/ضريبة/هامش) ثم **تقديم العرض**.
5. عند النتيجة: **ترسية (فائز)** أو **خاسر** (تُحفظ الأسعار في الذاكرة تلقائياً).
6. للفائز: **تحويل لمشروع** (يُنشئ المشروع ويولّد المراحل الخمس).

### ٢) الجدول الزمني (WBS)
1. من المشروع: زر **«توليد المراحل الخمس»** (إن لم تكن مولّدة).
2. **«استيراد الجدول الزمني»** من Excel، أو أضف الأنشطة يدوياً واربطها ببنود BOQ.
3. اعرض **Gantt** (يتطلب تثبيت موديول «رواسي سما — مخطط جانت»).

### ٣) المشتريات والميزانية
1. **طلبات المواد ← جديد**: اختر المشروع وأضف السطور (كل سطر = بند BOQ + كمية + تكلفة).
   - لو السطر يتجاوز المتبقي للبند يظهر تنبيه أحمر.
2. **تقديم** ← **اعتماد**. عند التجاوز يلزم **«اعتماد تجاوز الميزانية»** (مدير المشاريع).
3. **«إنشاء أمر شراء»** من الطلب المعتمد ← **تأكيد**.
4. **«استلام مواد»** (سند GRN) ← **تأكيد الاستلام**.
5. تابع **لوحة الميزانية** لكل بند (مرتبط/منفَق/متبقٍ/الحالة).

### ٤) المستندات والجودة والموقع
- **مستند (DMS)**: أنشئ، أرفق الملفات، أرسل للمراجعة ← اعتماد.
- **اعتماد مادة (MAS)**: اختر بند BOQ والمادة، أرفق الكتالوجات (PDF)، **رفع للاستشاري**،
  ثم **«توليد ملف مدموج (PDF)»** لإنتاج ملف موحّد. الاستشاري: اعتماد / مع ملاحظات / رفض.
- **التقرير اليومي (DSR)**: التاريخ، الطقس، سطور العمالة، الأعمال، الصور ← اعتماد.
- **عدم مطابقة (NCR)**: الموضوع، الخطورة، الوصف ← بدء المعالجة ← إغلاق (يسجّل التاريخ).
- **طلب معلومات (RFI)**: الاستفسار ← إرسال ← تسجيل الرد (إلزامي) ← إغلاق.

### ٥) العقود والمستحقات
- **أمر تغيير (VO)**: أضف سطور (زيادة/تخفيض كمية بند، أو بند جديد) ← تقديم ←
  **«اعتماد وتطبيق على BOQ»** (يحدّث جدول الكميات فعلياً).
- **مستخلص (IPC)**: اختر المشروع ← **«توليد البنود من المشروع»** ← أدخل **كمية الفترة**
  لكل بند ← تظهر الكمية التراكمية ونسبة الإنجاز والقيم ← اضبط نسبة المحتجز/الدفعة
  المقدمة ← **تقديم ← اعتماد ← تعليم كمدفوع**. (لا تتجاوز الكمية التعاقدية.)
- **ضمان بنكي (BG)**: النوع، البنك، رقم الضمان، المبلغ، تاريخ الانتهاء. النظام ينبّه
  قبل الانتهاء بـ ٣٠ يوماً ويوسم المنتهي تلقائياً.

### ٦) الطباعة والتقارير والتصدير
- **طباعة تقرير**: افتح السجل ← أيقونة الطباعة 🖨️ (أعلى) ← اختر التقرير (PDF بكل الحقول).
- **طباعة مع المرفقات**: في المستندات/الجودة، زر **«طباعة مع المرفقات»** (يدمج التقرير + ملفات PDF).
- **التصدير إلى Excel**: من أي قائمة، حدّد السجلات ← ⚙️ ← «تصدير»؛ أو من **اللوحات
  (Pivot)** زر التصدير.

### ٧) الفاتورة الضريبية (ZATCA)
- في المستخلص: يظهر **رمز QR** متوافق مع ZATCA وتفصيل الضريبة على التقرير.
- تأكد من إدخال **الرقم الضريبي للشركة** في إعدادات الشركة ليظهر في الرمز/الفاتورة.

## ثالثاً: ملاحظات مهمة للفريق
- **الحذف/الإلغاء/الإرجاع لمسودة** غير متاح لعامة المستخدمين عمداً — راجع مدير النظام عند الحاجة.
- **بند جدول الكميات هو الأساس**: احرص على ربط كل حركة بالبند الصحيح لتبقى الميزانية والتقارير دقيقة.
- **ذاكرة الأسعار** تتحسّن مع كل منافسة تُقدَّم — استفد من الاقتراحات في التسعير.
- لأي خطأ يظهر أثناء العمل، صوّر الشاشة وأرسلها لمسؤول النظام لمعالجتها بسرعة.
