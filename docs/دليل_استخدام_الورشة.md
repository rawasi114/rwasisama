# دليل استخدام نظام إدارة ورشة رواسي سما

> دليل عملي موجز لكل موظفي الشركة لاستخدام نظام الورشة داخل أودو.

---

## ١. ما هو النظام؟

موديول داخل أودو يدير دورة حياة العمل الكاملة في ورشة رواسي سما للمقاولات (نجارة / حدادة / ألمنيوم / CNC)، ابتداءً من عرض السعر للعميل وحتى إغلاق المشروع وتقييمه.

النظام يربط بين:
- المبيعات (عرض السعر وأمر البيع)
- التصنيع (أمر التشغيل + المراحل)
- المشتريات (RFQ + استلام المواد)
- المخزون
- التسليم وتوقيع العميل

---

## ٢. الأدوار والمسؤوليات

| الدور | المسؤوليات الأساسية |
|---|---|
| موظف المبيعات | إصدار عروض الأسعار، تأكيدها، متابعة دفعات العملاء |
| الفنّي / موظف الورشة | تحديد المواد المطلوبة، تنفيذ التصنيع، تسليم العميل |
| مشرف الورشة | الاعتماد الفنّي لطلبات المواد، الإشراف اليومي والتقارير |
| موظف الحسابات | اعتماد تمويل المشتريات وتوفير السيولة |
| موظف المشتريات | إصدار RFQ في تطبيق المشتريات وتسليم المواد للورشة |
| المفتش الفنّي / الجودة | فحص الجودة (QC) ورصد عدم المطابقة (NCR) |
| مدير العمليات | اعتماد نهائي، إشراف عام، متابعة الأداء |

---

## ٣. السير الكامل لأمر التصنيع

```
عرض السعر (أمر البيع)
        │ تأكيد العرض
        ▼
أمر تصنيع تلقائي (M-XXXXX)
        │ سداد ≥ ٥٠٪ من قيمة الطلب
        ▼
الفنّي يحدّد المواد ويطلب الاعتماد
        ▼
مشرف الورشة (اعتماد فنّي)
        ▼
موظف الحسابات (اعتماد تمويل + توفير سيولة)
        ▼
موظف المشتريات (RFQ → شراء → استلام في المخزون)
        ▼
تسليم المواد للورشة (توقيع المستلم)
        ▼
تأكيد التصنيع → بدء التصنيع → إنهاء التصنيع
        │ سداد ١٠٠٪ من قيمة الطلب
        ▼
التسليم للعميل (توقيع)
        ▼
إغلاق المشروع (إقرار + استبيان + توقيع المستلم)
```

## ٤. تعليمات لكل دور

### ٤.١ موظف المبيعات

**إصدار عرض السعر:**
1. افتح تطبيق «المبيعات» → عرض سعر جديد.
2. اختر العميل، وأضف المنتجات (تأكد أن المنتجات الورشية معلَّمة في بطاقة المنتج بحقل «يُصنّع في الورشة»).
3. أكّد العرض ← يُنشأ النظام تلقائياً أمر تصنيع برقم مرتبط (مثلاً S00006 → M00006).

**متابعة دفعات العميل:**
1. افتح أمر البيع → الزر الذكي «دفعات العميل».
2. سجّل كل دفعة: التاريخ، المبلغ، طريقة الدفع (نقدي/تحويل/شيك)، مرجع العملية.
3. النظام يحسب نسبة السداد ويفتح تلقائياً بوابات التصنيع والتسليم.

> ملاحظة: لا يمكن إنشاء أمر تصنيع يدوياً — التوليد تلقائي عند تأكيد عرض السعر فقط.

### ٤.٢ الفنّي / موظف الورشة (مُعدّ طلب المواد)

**تحديد المواد:**
1. افتح أمر التصنيع المطلوب.
2. تأكد من سداد ≥ ٥٠٪ (تنبيه أصفر يظهر إن لم يُسدَّد).
3. تبويب «المواد اللازمة» ← أضف المواد الخام (يظهر فقط الأصناف القابلة للشراء وغير القابلة للبيع).
4. لكل بند: المادة، الكمية المطلوبة، اختياري المورّد المقترح.
5. النظام يعرض الكمية المتوفرة بالمخزون تلقائياً.

**طلب الاعتماد:**
1. اضغط «طلب اعتماد المواد».
2. في المعالج: اختر مشرف الورشة المسؤول ← تأكيد.
3. يصل إشعار للمشرف (Activity).

**إذا أُعيد الطلب للتعديل:**
- اقرأ سبب الإعادة في الحقل أعلى الصفحة.
- عدّل المواد، ثم أعد إرسال طلب الاعتماد.

**بدء وإنهاء التصنيع:**
1. بعد تسليم المواد للورشة، اضغط «تأكيد التصنيع».
2. اضغط «بدء التصنيع» (شرط: ≥ ٥٠٪ سداد).
3. نفّذ العمل، وحدّث بنود التنفيذ.
4. عند الانتهاء: «إنهاء التصنيع».

### ٤.٣ مشرف الورشة (الاعتماد الفنّي)

**عند وصول طلب مواد:**
1. تصلك مهمة في «الأنشطة» الخاصة بك.
2. افتح أمر التصنيع ← راجع المواد والكميات.
3. **للاعتماد:** «اعتماد وإرسال للحسابات» ← اختر موظف الحسابات ← تأكيد.
4. **للرفض/الإعادة:**
   - اكتب السبب في حقل «سبب الرفض / الإعادة».
   - اضغط «رفض» (نهائي) أو «إعادة للتعديل» (يرجع للفنّي).

**التقارير اليومية (واجب):**
- **التحضير اليومي (RS-WS-05):** صباحاً — العمالة المتاحة/الغائبة، المعدات، الأعمال المخططة، قائمة الجاهزية.
- **التقرير اليومي (RS-WS-06):** نهاية اليوم — الإنجازات الفعلية، المعوقات، خطة الغد.
- **كشف الحضور (RS-WS-07):** يومي — دخول/خروج كل عامل.

### ٤.٤ موظف الحسابات (اعتماد التمويل)

**عند وصول طلب معتمد فنّياً:**
1. تصلك مهمة في «الأنشطة».
2. افتح أمر التصنيع ← راجع المواد والتكلفة المتوقعة.
3. وفّر السيولة اللازمة (خارج النظام، حسب إجراءات المالية).
4. **للاعتماد:** «اعتماد التمويل وإرسال للمشتريات» ← اختر موظف المشتريات ← تأكيد.
   - يُنشأ تلقائياً RFQ في تطبيق المشتريات.
   - يصل إشعار لموظف المشتريات.
5. **للرفض/الإعادة:** اكتب السبب، ثم رفض أو إعادة.

> مهم: لا يُنشأ طلب الشراء (RFQ) إلا بعد اعتمادك ماليّاً — حماية للالتزام قبل توفير السيولة.

### ٤.٥ موظف المشتريات

**عند وصول RFQ:**
1. تصلك مهمة في «الأنشطة».
2. افتح تطبيق «المشتريات» ← اعمل على RFQ المرتبط بأمر التصنيع.
3. عرض الأسعار، اختيار مورّد، تأكيد طلب الشراء.
4. عند استلام البضاعة، نفّذ الاستلام (Goods Receipt) كالمعتاد في المشتريات.

**تسليم المواد للورشة:**
1. ارجع لأمر التصنيع.
2. اضغط «تسليم المواد للورشة».
3. اكتب اسم مستلم المواد (من فنّيي الورشة).
4. خذ توقيعه في حقل التوقيع.
5. تأكيد.

### ٤.٦ المفتش الفنّي / الجودة

**فحص الجودة (RS-WS-15):**
- خلال/بعد التصنيع، أنشئ تقرير فحص.
- قائمة فحص ببنود (معيار + قراءة فعلية + يطابق/لا يطابق).
- القرار: قبول / قبول مع ملاحظات / إعادة عمل / رفض.

**عدم المطابقة (NCR — RS-WS-16):**
- صنّف عدم المطابقة (كبرى/صغرى/ملاحظة/متكررة).
- حلّل السبب الجذري.
- اكتب الإجراءات التصحيحية والوقائية، مع المسؤول وتاريخ التنفيذ.

**إعادة الأعمال:**
- عند الحاجة، أنشئ سجل إعادة عمل مع السبب والكمية والساعات التقديرية.
- اربطه اختيارياً بـ NCR ذي الصلة.

### ٤.٧ مدير العمليات (التسليم والإغلاق)

**التسليم للعميل:**
1. بعد إنهاء التصنيع وسداد ١٠٠٪، يصبح زر «التسليم للعميل» متاحاً.
2. تبويب «التسليم وتوقيع العميل»: اكتب اسم العميل، التاريخ، التوقيع.
3. اضغط «التسليم للعميل».

**إغلاق المشروع:**
1. اضغط «إغلاق» ← يفتح نموذج إغلاق المشروع.
2. في صفحة «الإقرار والاستبيان والتسليم»:
   - **١) الإقرار:** يكتبه العميل (نص حر).
   - **٢) الاستبيان:** تقييم الفنيين + جودة التشطيب + رضا العميل.
   - **٣) المستلم والتوقيع:**
     - اسم العميل يظهر تلقائياً من أمر البيع.
     - إذا كان المستلم غير العميل: فعّل خيار «المستلم غير العميل صاحب الدفع» واكتب اسم المستلم + صلة قرابته.
     - توقيع واحد للمستلم.
3. اعتماد مدير العمليات (اسم + توقيع + ختم).
4. اعتبائياً: قائمة التحقق من الإغلاق + قائمة الملاحظات المتبقية (Punch List).
5. اضغط «إغلاق المشروع».

> ⚠ **تنبيه:** بعد إغلاق المشروع، **لا يمكن إعادة فتحه أو تغيير حالته بأي طريقة**. هذا قرار نهائي.

**متابعة الأداء (شهري):**
- لوحة الأداء (Performance Score):
  - التسليم بالموعد %
  - رضا العميل %
  - الحضور %
  - نمو الإنتاجية %
- الدرجة الإجمالية + التقييم (ممتاز / جيد جداً / جيد / مقبول / ضعيف).
- تحليل أوامر التصنيع (Pivot/Graph).

## ٥. الجودة والسلامة (مشترك)

### اجتماع السلامة اليومي (RS-WS-18)
- موضوع، نقاط رئيسية، مخاطر محددة، قائمة الحضور بتوقيع كل حاضر.

### المعاينة وقياس الموقع (RS-WS-10)
- قبل التصنيع، الفنّي يقيس الموقع ويوثّق الأبعاد والمخططات.

### سجل الصيانة (RS-WS-17)
- وقائي (يومي/أسبوعي/شهري/سنوي) وعلاجي للمعدات، مع قطع الغيار وساعات التوقف.

## ٦. قواعد ذهبية يجب احترامها

1. **التوليد تلقائي:** أمر التصنيع يُنشأ فقط من تأكيد عرض السعر — لا تحاول إنشاءه يدوياً.
2. **بوابة ٥٠٪:** لا تُطلب مواد ولا يبدأ تصنيع قبل سداد ٥٠٪ من قيمة الطلب.
3. **بوابة ١٠٠٪:** لا تُسلَّم بضاعة للعميل قبل سداد كامل القيمة.
4. **اعتماد المواد ثلاثي:** مشرف الورشة → الحسابات → المشتريات. RFQ لا يُنشأ إلا بعد اعتماد الحسابات.
5. **أمر التصنيع المغلق نهائي:** لا يُعاد فتحه، ولا تتغيّر حالته، بأي طريقة. أنشئ أمراً جديداً إن لزم.
6. **المواد الخام فقط:** تظهر في قائمة الاختيار الأصناف المعرَّفة في المخزون كـ«تُشترى ولا تُباع».
7. **التوقيعات الإلكترونية معتمدة:**
   - توقيع مستلم المواد عند تسليمها للورشة.
   - توقيع العميل عند التسليم النهائي.
   - توقيع المستلم في إغلاق المشروع (يغطي الإقرار والاستبيان).
8. **اعتمادان في النماذج:** معد النموذج + مدير العمليات (وُحّدت من ٣ توقيعات إلى ٢).
9. **الإشعارات (Activities):** كل دور يصله إشعار عند وصول الدور إليه — راجع «الأنشطة الخاصة بك» يومياً.

---

## ٧. الدعم والتواصل

- **مشاكل تقنية أو استفسار عن النظام:** التواصل مع مدير العمليات أو الإدارة.
- **لا تحاول** تعديل البيانات مباشرة من قاعدة البيانات أو تجاوز سير العمل المحدد.
- **اقتراحات تحسين:** ترفع للإدارة لتقييمها وتطبيقها بعد المراجعة.
