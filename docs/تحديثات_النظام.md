# تحديثات نظام رواسي سما — قطاع المقاولات
### ملخّص التحسينات (للتعميم على الفريق)

> هذه قائمة بأبرز التحسينات والمزايا الجديدة التي أُضيفت في التحديث الأخير.
> الإصدار: 19.0.7.6.1 — على Odoo 19.

---

## ١. نظام المشاريع الخاص بنا
- أصبحت هناك **قائمة «المشاريع»** مستقلة داخل تطبيق رواسي سما (تعرض مشاريع
  المقاولات فقط).
- لكل مشروع: **المنافسة المصدر** + **ملخّص الميزانية** (التعاقدية / المستهلك /
  المتبقي) محسوبة تلقائياً من بنود جدول الكميات.
- نموذج المشروع يعرض قسم «معلومات المقاولات» + أزرار إحصائية سريعة (WBS،
  المستندات، اعتماد المواد، التقارير اليومية، عدم المطابقة، طلبات المعلومات).

## ٢. الترقيم التلقائي والبحث الموحّد
- **رقم تسلسلي تلقائي للمنافسة**: `RS-TND-2026####` (يتغيّر العام تلقائياً).
- **رقم تسلسلي تلقائي للمشروع**: `RS-PRJ-2026#####`.
- يمكن **البحث بالاسم أو بالرقم التسلسلي** في خانة البحث مباشرةً.
- اسم المشروع يبقى **نظيفاً**، والرقم التسلسلي يظهر كحقل ثابت (للقراءة فقط).

## ٣. المراحل الرئيسية الست للمشروع
استُبدلت المراحل القديمة بـ **٦ مراحل معيارية برموزها**، وتُولَّد تلقائياً عند
تحويل المنافسة لمشروع (أو بزر «توليد المراحل»):

| الرمز | المرحلة |
|---|---|
| INT-01 | التأسيس والانطلاق |
| PLN-02 | التخطيط الشامل |
| SIT-03 | استلام الموقع |
| EXE-04 | التنفيذ والاعتمادات |
| M&C-05 | المراقبة والتحكم |
| CLO-06 | الإغلاق والتسليم |

- لكل مرحلة **مهام قياسية فرعية** تُنشأ تلقائياً (قابلة للتعديل أو **الحذف** من
  الموظف حسب الحاجة).
- المراحل والمهام تأخذ **تواريخ افتراضية متسلسلة** لتظهر مباشرةً على الجدول الزمني.

## ٤. الجدول الزمني (Schedule)
- **زر «قالب الجدول الزمني»**: ينزّل ملف Excel جاهزاً للتعبئة (بكل الأعمدة + ورقة
  بأسماء المراحل) — يعبّئه الموظف ويعيد رفعه.
- **الاستيراد يدعم كل الحقول**: النشاط، المرحلة، التسلسل، تاريخ البداية/النهاية،
  **بداية/نهاية خط الأساس**، **البداية/النهاية الفعلية**، نسبة الإنجاز، معلَم.
- **مستند طباعة احترافي أفقي (Landscape)** للجدول الزمني على شكل **Gantt**:
  أشرطة ملوّنة على محور بالأشهر، مع تمييز **المسار الحرج بالأحمر** (يُحسب بطريقة
  CPM عبر علاقات الأسبقية)، والمعالم بالبنفسجي، والأنشطة العادية بالأزرق.

## ٥. التسعير والاستيراد الذكي
- **استيراد جدول كميات مُسعّر**: إذا احتوى ملف الإكسل على أعمدة الأسعار (سعر الوحدة
  / إجمالي السعر / التكلفة)، تُرفع الأسعار تلقائياً ويُعامَل البند كأنه سُعّر يدوياً.
- **الذكاء التسعيري**: تُحفظ أسعار البنود تلقائياً في «ذاكرة الأسعار» عند التقديم،
  مع **اقتراح أسعار تاريخية مشابهة** وزر «تطبيق أفضل سعر» أثناء التسعير.

## ٦. العقود والمستحقات
- **أوامر التغيير (VO)**: تُطبَّق على جدول الكميات عند الاعتماد (زيادة/تخفيض كميات
  أو بند جديد) مع حساب صافي الأثر المالي.
- **المستخلصات (IPC)**: توليد بنود من المشروع، حساب الكمية السابقة/التراكمية ونسبة
  الإنجاز، **محتجز الضمان + استرداد الدفعة المقدمة + الضريبة**، ومنع تجاوز الكمية
  التعاقدية.
- **الضمانات البنكية**: تتبّع تاريخ الانتهاء مع **تنبيه تلقائي** قبل الانتهاء بـ
  ٣٠ يوماً ووسم المنتهية.

## ٧. التقارير والطباعة
- **تقرير PDF لكل سجل** يحتوي كل حقول النموذج (يظهر في قائمة الطباعة 🖨️).
- في السجلات ذات المرفقات: زر **«طباعة مع المرفقات»** يدمج التقرير مع ملفات PDF في
  ملف واحد.
- **فاتورة المستخلص متوافقة مع ZATCA** (رمز QR + تفصيل الضريبة + الرقم الضريبي).

## ٨. لوحات وتحليلات
قائمة **«لوحات وتحليلات»** بثلاثة أقسام (رسوم بيانية ومحورية قابلة للتصدير Excel):
- **تنفيذية**: تحليل المنافسات + المستخلصات (الإيراد).
- **المشاريع**: استهلاك الميزانية.
- **المخاطر**: عدم المطابقة + طلبات المعلومات + الضمانات البنكية.

## ٩. الحوكمة والصلاحيات
- قاعدة: **الإلغاء / الإرجاع لمسودة / الحذف** متاح لمستخدمي **الإدارة (Admin) فقط**؛
  أي سجل يُسجَّل يبقى للسجل المؤسسي.
- **استثناء**: أنشطة الجدول الزمني (WBS) **قابلة للحذف من الموظف** (لإزالة المراحل/
  المهام الافتراضية غير المطلوبة).

## ١٠. إصلاحات مهمة
- تصحيح عرض **نِسَب الإنجاز/الاستهلاك** (كانت تظهر مضروبة ×100).
- توافق التقارير مع **تخطيط الترويسة المخصّص** في النظام.
- إصلاح **تحويل المنافسة لمشروع** (تعارض مع موديول المستندات في Enterprise).
- **ترقية آمنة** عبر سكربتات ترحيل (تنظيف العروض القديمة واستبدال المراحل).

---

## كيف يبدأ الموظف؟ (دورة مختصرة)
1. **منافسة جديدة** → يظهر رقم `RS-TND` تلقائياً → استيراد جدول الكميات (مُسعّر أو لا)
   → تسعير → تقديم → ترسية → **تحويل لمشروع** (رقم `RS-PRJ` + المراحل الست).
2. **الجدول الزمني**: «قالب الجدول الزمني» للتعبئة، ثم «استيراد»، ثم «طباعة الجدول
   الزمني» للمستند الأفقي الملوّن.
3. **التنفيذ**: طلبات المواد ← أوامر الشراء ← الاستلام، واعتماد المواد، والتقارير
   اليومية، وعدم المطابقة، وطلبات المعلومات.
4. **المستحقات**: أوامر التغيير، المستخلصات، الضمانات البنكية.
5. **المتابعة**: لوحات التحليل والتقارير والطباعة.

> لأي خطأ يظهر أثناء العمل: صوّر الشاشة وأرسلها لمسؤول النظام.
