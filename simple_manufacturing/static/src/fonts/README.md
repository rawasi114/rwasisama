# خطوط التقارير (Tajawal)

ضع هنا ملفّي الخط الحقيقيين لاستخدامهما في طباعة التقارير:

- `Tajawal-Regular.ttf`
- `Tajawal-Bold.ttf`

تُنزّل من Google Fonts (Tajawal) وتوضع في هذا المجلد بهذين الاسمين بالضبط.

ملاحظة: قالب التقارير يشير إلى هذين الملفين عبر `@font-face`. في حال
غيابهما يستخدم النظام خطاً عربياً افتراضياً تلقائياً (fallback)، فلا تظهر
دوائر فارغة. لتفعيل خط Tajawal رسمياً في الـPDF (يعمل بلا إنترنت) أسقِط
الملفين هنا فقط.
