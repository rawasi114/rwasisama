# rawasi_workshop — الورشة

موديول إدارة الورشة (النجارة والحدادة). يعتمد على `rawasi_base` ويستخدم هويته ومجموعاته.

## المُنفَّذ (Phase 0)
- هيكل الموديول + المجموعات الخاصة + قائمة «الورشة» تحت الجذر الموحَّد.

## المُخطَّط (Phase 6–7)
- الأقسام `rawasi.workshop.section` (CARP / STEEL).
- أوامر التصنيع `rawasi.workshop.mo` + بوابات الدفع (٥٠٪ / ١٠٠٪).
- تكامل أوامر البيع + الصرف بـ PIN + أوامر العمل + التقارير.
- نقطة استقبال التصنيع الداخلي من المقاولات + التسليم التلقائي للمشروع.

## المجموعات الخاصة
- `group_worker` — عامل/فني ورشة
- `group_supervisor` — مشرف ورشة (يرث الفني)

> المحاسبة/المشتريات/الأدمن من `rawasi_base`.
