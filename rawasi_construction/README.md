# rawasi_construction — المقاولات

موديول إدارة المقاولات. يعتمد على `rawasi_base` ويستخدم هويته ومجموعاته وشجرة حساباته.

## المُنفَّذ (Phase 0)
- هيكل الموديول + المجموعات الخاصة + قائمة «المقاولات» تحت الجذر الموحَّد.

## المُخطَّط (Phase 4–5, 7)
- المنافسات + جداول الكميات (BoQ) + الترسية.
- المشاريع: دورة الحياة، الميزانيات، الربحية.
- التنفيذ: DSR، MR، PO، GRN، IPC، VO، مقاولو الباطن، الضمانات.
- قوائم المواد `rawasi.bom`.
- التصنيع الداخلي: `procurement_type = in_house_workshop` (ربط مع الورشة).

## المجموعات الخاصة
- `group_site_engineer` — مهندس موقع
- `group_project_manager` — مدير مشروع (يرث مهندس الموقع + المكتب الفني)
- `group_technical_office` — المكتب الفني

> المحاسبة/المشتريات/الأدمن من `rawasi_base`.
