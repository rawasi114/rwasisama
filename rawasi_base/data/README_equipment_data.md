# بيانات الأصول الثابتة الأولية

الأمر الهندسي يطلب تحميل 4 قوائم أصول أولية:
- ٣٨ أصلاً مكتبياً (أثاث/أجهزة/كاميرات)
- ٤ سيارات
- ١٧ آلة ورشة (≈ ١٥١٬٠٠٠ ريال)
- ٢٦ أداة موقع (≈ ١٢٬٠٠٠ ريال)

> **ملاحظة مهمة:** ملفّا الـ PDF المرفقان لقوائم الأصول عبارة عن **صور ممسوحة ضوئياً**
> (بلا طبقة نص قابلة للاستخراج)، ولم تتوفّر أداة OCR في بيئة التنفيذ. لذلك لم
> تُولَّد سجلات أصول وهمية تفادياً لإدخال بيانات مالية غير دقيقة.

## كيف تُحمَّل القوائم الفعلية
استخدم خاصية **الاستيراد** في Odoo على نموذج «الأصول الثابتة»:
1. افتح: رواسي سما ← الأصول الثابتة ← (favorites) ← Import records.
2. استخدم القالب [`equipment_import_template.csv`](./equipment_import_template.csv) كبنية أعمدة.
3. قيم حقل `category` الصحيحة:
   `office_furniture` · `office_electronics` · `vehicle` ·
   `workshop_machine` · `site_tool` · `camera_system`.
4. حقل `code` يُولَّد تلقائياً (EQ-#####) — اتركه فارغاً.

بدّل أسطر الأمثلة في القالب ببيانات القوائم الأربع الفعلية ثم استورد.
