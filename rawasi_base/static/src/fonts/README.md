# خطوط رواسي سما

## الخط الرسمي للعلامة (Brand Guidelines · Rawasi.pdf)
- **DIN Next LT Arabic** — الخط الرئيسي (عربي + لاتيني، أوزان UltraLight→Black).
- **GE SS Two** — للمحتوى العربي · **WinSoft Pro** — للإنجليزية الثانوية.

> هذه خطوط تجارية مرخّصة. أضِف ملفات `.ttf/.otf` المرخّصة هنا للإنتاج،
> ثم سجّلها في `__manifest__.py` (assets) وأضف قواعد `@font-face` في
> `../scss/rawasi_report.scss`.

## البديل الحر المستخدم افتراضياً
وفق الأمر الهندسي، يُستخدم **Cairo** (مفتوح المصدر) كبديل عملي قابل للتضمين.
لتنزيله محلياً عند توفّر الشبكة:

```bash
bash tools/fetch_fonts.sh
```

سيضع `Cairo-Regular.ttf` و `Cairo-Bold.ttf` في هذا المجلد. بعد ذلك فعّل
قواعد `@font-face` وأضِف الملفّين إلى `web.report_assets_common` في المانيفست.

> حالياً يعتمد التصميم على تدرّج خطوط (font stack) يضمن عرضاً عربياً سليماً
> دون الحاجة لملفات خطوط مضمّنة، لتفادي مراجع ملفات مفقودة.
