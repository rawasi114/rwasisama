# rawasi_base — الأساس المشترك

الموديول الأساس لنظام رواسي سما الموحَّد. يوفّر المكوّنات المشتركة بين موديولي
المقاولات والورشة ويمنع تكرارها.

## المُنفَّذ (Phase 1)
- **المجموعات المشتركة:** `group_rawasi_admin` / `group_rawasi_accountant` / `group_rawasi_procurement` ضمن فئة «رواسي».
- **شجرة الحسابات:** ٢٧٢ حساباً (`data/rawasi_chart_of_accounts.xml`) — مُولَّدة من المصدر المعتمد، أكواد فريدة، أنواع Odoo صحيحة.
- **الخطط التحليلية:** «رواسي» ← مشاريع المقاولات / أقسام الورشة (متعددة الأبعاد).
- **الأصول الثابتة:** `rawasi.equipment` + تسلسل ترقيم + شاشات + قائمة.
- **الهوية البصرية:** قالب تقارير موحَّد `rawasi_base.rawasi_layout` + paperformat + SCSS (ألوان الدليل الرسمي + تدرّج خطوط Cairo).

## المُخطَّط لاحقاً
- المرحلة 2: الإشعارات (`rawasi.notification.hook`) + DMS + Audit + سلاسل الاعتماد + PIN + الإعدادات.
- المرحلة 3: `rawasi.material.request.base` (مجرّد) + اختبارات الأساس.

## ملاحظات
- كل المعرّفات الخارجية مسبوقة بـ `rawasi_base.`.
- `application = False` (موديول تقني أساس).
- ألوان الهوية الرسمية: Navy `#253747` · Gold `#BD9B5E` · Cream `#F0E8DA`.
