# Rawasi Sama — HR (`rawasi_hr`)

موديول الموارد البشرية (HR‑5) لنظام رواسي سما. يضيف قدرتين متوافقتين مع نظام
العمل السعودي:

## 1. مكافأة نهاية الخدمة (`rawasi.eos.settlement`)
احتساب آلي وفق المواد 84 و85 و87:
- نصف شهر عن كل سنة من السنوات الخمس الأولى، وشهر كامل عمّا بعدها.
- نِسَب الاستقالة: <2 سنة = 0، 2–5 = ⅓، 5–10 = ⅔، ≥10 = كامل.
- استحقاق كامل للإنهاء/انتهاء العقد/الوفاة/الحالات الخاصة، وصفر للفصل النظامي.
- توليد القيد المحاسبي (مدين مخصص نهاية الخدمة / دائن مستحقات الموظف).
- **وعاء الأجر قابل للضبط**: الأجر الشامل / الأساسي + السكن / الأساسي فقط.

## 2. المخصص الشهري (`rawasi.eos.provision.run`)
يحسب الالتزام المتراكم لكل موظف ويُرحِّل فرق الشهر كمصروف، مع مهمة `ir.cron`
شهرية (مُعطَّلة افتراضياً حتى ضبط الحسابات وتفعيلها).

## 3. حماية الأجور (`rawasi.wps.batch`)
توليد ملف SIF لدفعة رواتب شهرية، قابل للتنزيل ورفعه للبنك. **صيغتان قابلتان
للاختيار**: `generic` و`mudad`.

## الإعداد
بعد التثبيت، من **الإعدادات ← رواسي سما ← الموارد البشرية ونهاية الخدمة**:
رقم المنشأة في مكتب العمل، حساب بنك الرواتب، يومية وحسابات نهاية الخدمة.
ثم عرّف تركيبة أجر كل موظف في تبويب «الأجر وحماية الأجور».
